1. PROPÓSITO DO SISTEMA
════════════════════════════════════════════════════════════════════════════════

Painel de gestão de processos de pagamento para a Secretaria Municipal de 
Educação de Itaguaí (SMEDU-C). O sistema centraliza e monitora o fluxo de 
tramitação de processos, oferecendo:

  ✓ Dashboard analítico com KPIs
  ✓ CRUD de processos e configurações
  ✓ Autenticação + controle de acesso baseado em roles
  ✓ Exportação de dados (PDF, Excel)
  ✓ Timeline de movimentações
  ✓ Acesso via PWA (instalável como app)
