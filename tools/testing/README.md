# Testing Tools

This directory contains development and testing utilities used during development.

## Files

- `check_errors.js` - Puppeteer-based error checking script
- `test_filter_dom.js` - Playwright-based DOM filter testing
- `extract.py` - Python utility for extracting data from files
- `find_lines.py` - Python utility for finding specific lines
- `search.py` - Python search utility
- `test_menu.py` - Menu testing script

## Usage

These are development-only tools and should not be included in production builds.

## Notes

- These tools require development dependencies (puppeteer, playwright, Python)
- Not part of the main application build process
- Used for debugging and testing during development
