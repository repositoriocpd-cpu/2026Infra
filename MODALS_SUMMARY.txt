PADRÕES DE BOTÃO FECHAR:
========================

PADRÃO 1: Com Ícone X
├─ HTML: <button class="modal-close" onclick="window.closeModal('id')"><i class="fas fa-times"></i></button>
├─ CSS: background: transparent; border: none; font-size: 1.5rem; cursor: pointer;
└─ Hover: color #dc3545; transform: scale(1.1);

PADRÃO 2: Texto "Fechar"
├─ HTML: <button class="btn btn-secondary" onclick="window.closeModal('id')">Fechar</button>
├─ CSS: Segue padrão de botões do sistema
└─ Hover: Efeito padrão dos botões

PADRÃO 3: Fechar por Backdrop
├─ HTML: onclick="if(event.target===this) window.closeModal('id')"
├─ Comportamento: Apenas se clicar fora do conteúdo
└─ Uso: Modais de processo, configuração

PADRÃO 4: Close-Sidebar (Menu)
├─ HTML: <button class="close-sidebar" onclick="window.toggleMenu()"><i class="fas fa-times"></i></button>
├─ CSS: Ícone branco, transparent background
└─ Uso: Botão dentro do header do menu lateral

PADRÃO 5: Cancelar (Confirmação)
├─ HTML: <button class="btn btn-secondary" onclick="window.ConfirmModal.cancel()">Cancelar</button>
├─ CSS: Segue padrão de botões secundários
└─ Uso: Modal de confirmação


HANDLERS DE CLIQUE PRINCIPAIS:
==============================

1. window.toggleMenu()
   ├─ Localização: 2026_script.js (linhas 6-16)
   ├─ Função: Alterna abertura/fechamento do menu
   ├─ Classes manipuladas:
   │   ├─ .side-menu → toggle 'open'
   │   └─ .overlay → toggle 'visible'
   ├─ Extras:
   │   ├─ Remove 'open' de todos os submenus
   │   └─ Remove 'active' de items com submenu
   └─ Status: Global

2. window.closeAllModals()
   ├─ Localização: 2026_script.js (linhas 18-28)
   ├─ Função: Fecha todas as modais conhecidas
   ├─ Modais fechadas:
   │   ├─ accessibility-modal
   │   ├─ cookie-modal
   │   ├─ processControlModal
   │   ├─ processConf
