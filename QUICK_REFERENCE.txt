FUNÇÕES GLOBAIS PRINCIPAIS:
===========================

window.toggleMenu()
├─ O que faz: Alterna abertura/fechamento do menu
├─ Uso: onclick="window.toggleMenu()"
└─ Classes: .side-menu.open, .overlay.visible

window.closeAllModals()
├─ O que faz: Fecha TODAS as modais abertas
├─ Uso: Automático ao abrir nova modal
└─ Classes: Remove .visible de todas

window.closeModal(id)
├─ O que faz: Fecha uma modal específica
├─ Uso: onclick="window.closeModal('id')"
└─ Classes: Remove .visible, set display: none

window.openProcessModal(p = null)
├─ O que faz: Abre modal de processo
├─ Uso: onclick="window.openProcessModal()"
├─ Parâmetro: p = null (novo) ou p = objeto (editar)
└─ Classes: Adiciona .visible, display: flex

window.openConfigModal(type)
├─ O que faz: Abre modal de configuração
├─ Uso: onclick="window.openConfigModal('users')"
├─ Tipos: users, departments, suppliers, objects, locations, statuses, handlers
└─ Classes: Adiciona .visible, display: flex

window.ConfirmModal.show(message, options)
├─ O que faz: Mostra modal de confirmação
├─ Uso: await window.ConfirmModal.show('Tem certeza?', {isDangerous: true})
├─ Retorna: Promise<boolean> (true = confirm, false = cancel)
└─ Eventos: ESC key, Backdrop click, Botões

EVENTOS ESPECIAIS:
==================

ESC Key (Qualquer Modal Aberta)
├─ Comportamento: Fecha a modal
├─ Implementação: document.addEventListener('keydown', (e) => { ... })
└─ Classes: Remove .visible

Backdrop Click (Modais)
├─ Comportamento: Fecha a modal
├─ Condição: if (event.target === modal)
└─ Classes: Remove .visible

Stop Propagation
├─ Uso: event.stopPropagation() em todos os handlers
├─ Propósito: Impedir que clique suba para overlay
└─ Crítico: Sem isso, botão "fechar" fecharia a modal

FLUXO TÍPICO - CRIAR PROCESSO:
==============================

1. Usuário clica "Novo Processo" no menu
2. onclick="window.openProcessModal(); window.toggleMenu();"
3. window.toggleMenu() fecha menu
4. window.openProcessModal(null) abre modal vazia
5. Usuário preenche formulário
6. Clica "Salvar"
7. Função valida e envia dados
8. window.closeAllModals() ou específica fecha tudo
9. Modal desaparece com animação
10. Sucesso: alert ou UIKit.showSuccessModal()


FLUXO TÍPICO - EDITAR PROCESSO:
==============================

1. Usuário clica botão editar na tabela
2. onclick="window.openProcessModal(processObject)"
3. window.openProcessModal(p) abre modal com dados
4. Título muda para "Editar Processo"
5. Formulário popula com dados existentes
6. Usuário modifica campos
7. Clica "Atualizar"
8. Função valida e envia dados
9. window.closeModal('processControlModal') fecha
10. Tabela atualiza (refresh)
