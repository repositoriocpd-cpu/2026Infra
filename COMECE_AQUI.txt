⚡ PASSO 1: INICIAR O SERVIDOR (Obrigatório!)
─────────────────────────────────────────────────────────────────────────

1. Abra PowerShell (Buscar: PowerShell)
   ou Command Prompt (cmd)

2. Cole este comando:
   cd E:\2026\ SISTEMAS\2025\ Infra\ Sistemas\ YASMIN

3. Pressione Enter

4. Cole este comando:
   python -m http.server 8000

5. Se funcionar, você verá:
   Serving HTTP on 0.0.0.0 port 8000 ...

6. Deixe essa janela aberta! ⚠️


🌐 PASSO 2: ABRIR O NAVEGADOR
─────────────────────────────────────────────────────────────────────────

1. Abra seu navegador favorito:
   Chrome, Firefox, Edge, Safari, etc.

2. Na barra de endereço, digite:
   http://localhost:8000

3. Pressione Enter

4. Você verá uma lista de arquivos

5. Clique em "index.html"

6. A aplicação carrega! 🎉

🔍 SE ALGO DER ERRADO
─────────────────────────────────────────────────────────────────────────

Problema: "Connection refused" ou "Erro de conexão"
Solução:
├─ Verifique se o PowerShell ainda está aberto
├─ Se não estiver, execute novamente:
│  cd E:\2026\ SISTEMAS\2025\ Infra\ Sistemas\ YASMIN
│  python -m http.server 8000
└─ Aguarde 5 segundos antes de recarregar a página

Problema: Botões ainda não funcionam
Solução:
├─ Verifica a URL da barra:
│  ❌ ERRADA: file:///E:/2026...
│  ✅ CORRETA: http://localhost:8000/index.html
└─ Se estiver errada, digite http://localhost:8000 novamente

Problema: Servidor diz "porta 8000 já está em uso"
Solução:
├─ Teste outra porta:
│  python -m http.server 8001
└─ Abre no navegador:
   http://localhost:8001
