🐛 TROUBLESHOOTING
─────────────────────────────────────────────────────────────────────────

PROBLEMA: Modal não fecha
SOLUÇÃO:
1. Verifica se está via servidor (http://, não file://)
2. Abre Console (F12)
3. Testa: window.closeModal('modal-id')
4. Verifica se há erro em vermelho
5. Se houver erro, copie e reporte

PROBLEMA: Overlay fica visível
SOLUÇÃO:
1. Abre Console
2. Testa: document.getElementById('overlay').style.display = 'none'
3. Se sumir, há bug em closeModal
4. Reporte com screenshot

PROBLEMA: Transição não é suave
SOLUÇÃO:
1. Verifica se CSS transitional está carregado
2. Abre DevTools (F12) → Elements
3. Procura por .modal ou .process-modal
4. Verifica se tem "transition: opacity 0.3s"

PROBLEMA: Servidor não inicia
SOLUÇÃO:
1. Verifica se Python/Node está instalado
2. Tenta outra porta: python -m http.server 8001
3. Se ainda não funciona, instala Python do python.org
