Para um Desenvolvedor novo no projeto:
  1. Ler COMECE_AQUI.md (5 min)
  2. Ler REFERENCIA_RAPIDA.txt (5 min)
  3. Ler ANALISE_DETALHADA_COMPONENTES.md (30 min)
  4. Ver exemplos de código conforme necessário

Para corrigir um bug:
  1. Procurar o arquivo em ANALISE_INDICE_COMPLETO.md → "Referências cruzadas"
  2. Ler seção relevante em ANALISE_DETALHADA_COMPONENTES.md
  3. Ver solução em ANALISE_DETALHADA_PADROES.md
  4. Copiar exemplo e adaptar

Para adicionar uma feature:
  1. Ler ANALISE_DETALHADA_COMPONENTES.md → 1.1 (padrão modal)
  2. Criar novo modal seguindo exemplo
  3. Adicionar handler em 2026_script.js
  4. Atualizar window.state

Para refatoração:
  1. Ler ANALISE_DETALHADA_PADROES.md completo
  2. Usar seção 5 (Roadmap) como planejamento
  3. Usar seção 4 (Refatoração passo-a-passo) como guia

Para auditoria de segurança:
  1. Ler ANALISE_DETALHADA_SEGURANCA.md completo
  2. Seguir checklist na seção 4
  3. Implementar mitigações em ordem de prioridade
